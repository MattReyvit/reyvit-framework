# G1 — Planning & Design
- Clarify goal, users and success metric before building.
- Write a 1-page PRD (template in `templates/PRD.md`).
- Map the customer journey: discover → evaluate → convert → retain.
- Draft the data model (entities, relations, sensitive fields).
- Identify legal requirements early (personal data, invoicing, consumer rights).
- Check the reuse catalog before designing anything new.
