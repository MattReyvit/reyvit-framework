# G2 — UX/UI & SEO
## UX/UI
- Mobile-first, one primary action per screen, clear empty/error states.
- Accessibility: WCAG 2.2 AA (contrast, keyboard, labels, alt text).
- Design tokens; no hardcoded colors.
## SEO (single source of truth)
- Unique title (<60), meta description (<160), one H1 per page.
- Semantic HTML, canonical URLs, sitemap, robots.
- JSON-LD (Organization, LocalBusiness, Product, FAQ, Breadcrumb).
- E-E-A-T: author, contact, real evidence.
- GEO: concise answers, FAQs, entities clearly named for AI search.
- Core Web Vitals: LCP < 2.5s, INP < 200ms, CLS < 0.1.
